## 5. 缺陷与修复记录

| # | 缺陷 | 修复 |
| --- | --- | --- |
| 1 | time.strftime 误传 float → dashboard 500 | 统一 `time.localtime(time.time()-86400*n)` |
| 2 | 异常分支漏 import traceback | 补 import |
| 3 | API Key 生成 hashlib.sha256(str) 未编码 | 改用内部 sha() |
| 4 | 中文查询参数未编码 → ASCII 编码错误 | conftest req 统一 quote |
| 5 | GPA 150 分制换算测试预期错误 | 修正折算预期 |
| 6 | 同分并列排名等级断言错误 | 60 分=及格 |
| 7 | 风险评分 30 分档级判断 | 30 分→"提"（非"警"） |
| 8 | 100.005 HALF_UP 进位到 100.01 | 修正测试预期 |
| 9 | 首次启动崩溃造成残缺库（用户存在则跳过种子） | 测试一律用全新临时库 |
| 10 | 冒烟走系统代理 → 连接失败 | smoke 加 ProxyHandler({}) 直连 |

## 6. 结论

三道门禁全绿，**放行部署**。
