## 3. 常用操作

### 3.1 录入成绩
成绩管理 → 选学期/考试/班级 → 「+ 录入成绩」→ 填学号/课程代码/成绩 → 保存。同一学生同一考试重复录入为覆盖更新。

### 3.2 缴费核销
缴费管理 → 找到未缴清单据 → 「核销」。支持部分缴费；缴满应收（已扣折扣）自动变「已缴清」。逾期单在工作台与收缴汇总中高亮。

### 3.3 学籍变动（转班/休学/退学）
后端接口：`POST /api/transfers/save` 申请 → `POST /api/transfers/approve` 审批。转班审批通过后自动迁移班级并重算两班人数。

### 3.4 风险扫描
工作台或预警中心 → 「执行扫描」。三类规则：学费逾期未缴、期末挂科≥2 或均分<60、近 30 天旷课≥3。

### 3.5 导出学生名单
学籍管理或统计报表 → 「导出名单」→ CSV（UTF-8 BOM，Excel 直接打开）。

## 4. FAQ

**Q：改密后其他设备被踢出？**
改密会清空该账号全部令牌，需重新登录，属安全设计。

**Q：为什么我不能核销缴费？**
核销需要 finance 角色（fee.write）或 admin。教师/教务角色无此权限。

**Q：成绩录错了怎么改？**
同一学生+课程+考试再次录入即覆盖；审计日志保留操作痕迹。

**Q：对接方如何接入？**
系统管理 → 生成接口密钥（X-Edu-Key），对接文档见 `GET /api/apidoc` 与《接口契约》。

**Q：周课表怎么看冲突？**
课程排课页顶部自动红牌显示全部冲突（班级冲突/教师冲突）。

## 5. 技巧

- 学生搜索支持姓名/学号/监护人模糊匹配；
- 成绩分析页选「全部班级」看全校区，选具体班级看班内排名；
- 预警中心的扫描是幂等增量的：已存在的同标题预警不会重复生成；
- 工作台顶部的「逾期单」数即到期未缴清单据数，点缴费管理直接处理。
